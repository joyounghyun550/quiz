## 필수 주석 작성 대상

1. **모든 컴포넌트** - 최소한 한 줄 설명 + Props 설명
2. **모든 커스텀 훅** - 용도 + 파라미터 + 반환값 + 예시
3. **모든 API 함수** - 용도 + 에러 처리 + 예시
4. **모든 Props 타입** - 각 필드별 설명 + 옵션 여부 + 기본값
5. **복잡한 로직** - 인라인 주석으로 단계별 설명

## 좋은 주석 vs 나쁜 주석

### ❌ 나쁜 예

```typescript
/**
 * 유저를 가져오는 함수
 */
const getUser = () => {
  // ...
};

/**
 * 로그인 폼
 */
const LoginForm = () => {
  // ...
};

// 버튼 클릭
const handleClick = () => {
  // ...
};
```

**문제점:**

- 코드가 하는 일을 단순 반복
- 의도나 컨텍스트 설명 부족
- 사용법이나 주의사항 없음

### ✅ 좋은 예

````typescript
/**
 * 현재 로그인된 사용자의 프로필을 조회합니다
 *
 * 서버에서 인증 토큰을 확인하여 사용자 정보를 반환합니다.
 * 토큰이 없으면 401 에러가 발생합니다.
 *
 * @returns 사용자 프로필 (이름, 이메일, 약관 동의 여부)
 * @throws {AxiosError} 401 - 인증되지 않음
 *
 * @example
 * ```typescript
 * const profile = await getCurrentUserProfile();
 * if (!profile.isTermsAgreed) {
 *   router.push('/terms');
 * }
 * ```
 */
const getCurrentUserProfile = async (): Promise<UserProfile> => {
  // ...
};

/**
 * 로그인 폼 컴포넌트
 *
 * 소셜 로그인 (구글, 카카오, 네이버)을 제공합니다.
 * OAuth 2.0 방식으로 인증 서버로 리다이렉트합니다.
 *
 * ## 주요 기능
 * - 소셜 로그인 버튼 (3종)
 * - 로딩 상태 표시
 * - 로그인 성공 시 콜백 실행
 *
 * @param props - LoginFormProps
 * @example
 * ```tsx
 * <LoginForm onSuccess={() => router.push('/dashboard')} />
 * ```
 */
const LoginForm = ({ onSuccess }: LoginFormProps) => {
  // ...
};

/**
 * 로그인 버튼 클릭 핸들러
 *
 * 선택한 소셜 로그인 제공자(구글, 카카오, 네이버)로
 * OAuth 인증 페이지로 리다이렉트합니다.
 *
 * @param provider - 소셜 로그인 제공자
 */
const handleLoginClick = (provider: "google" | "kakao" | "naver") => {
  // ...
};
````

**장점:**

- 의도와 컨텍스트를 명확히 설명
- 사용법과 예시 제공
- 에러 처리 방법 설명
- 주의사항 명시

## 인라인 주석 작성 원칙

복잡한 로직에는 섹션 구분 주석과 인라인 설명을 추가합니다:

```typescript
export const useChatMessage = ({ isLoggedIn, userId }: UseChatMessageParams) => {
  // ============================================
  // 1. 상태 초기화
  // ============================================
  const [isSending, setIsSending] = useState(false);
  const [messages, setMessages] = useState<ChatMessage[]>([]);

  // ============================================
  // 2. sessionStorage 동기화
  // ============================================
  /**
   * sessionStorage의 isAnswering과 isSending 동기화
   * 다른 탭에서 sessionStorage가 정리되었을 때 isSending도 false로 설정
   */
  useEffect(() => {
    const isAnswering = sessionStorage.getItem("isAnswering");
    if (isAnswering !== "true" && isSending) {
      setIsSending(false);
    }
  }, [isSending]);

  // ============================================
  // 3. 메시지 전송 로직
  // ============================================
  /**
   * 메시지 전송 공통 로직
   * 회원/비회원 모두 사용 가능하며, 전송 제한을 확인합니다.
   *
   * @param messageText - 전송할 메시지 텍스트
   */
  const sendMessage = useCallback(
    async (messageText: string): Promise<void> => {
      // 전송 가능 여부 확인
      if (!canSend()) {
        return;
      }

      // 전송 중 상태로 변경
      setIsSending(true);
      sessionStorage.setItem("isAnswering", "true");

      try {
        // 1. 임시 사용자 메시지 추가
        const tempUserMessage = createTempUserMessage(messageText);
        setMessages((prev) => [...prev, tempUserMessage]);

        // 2. API 호출
        const response = await sendChatMessage({
          sessionId: currentSessionId,
          message: messageText,
        });

        // 3. AI 응답 메시지 추가
        const aiMessage = {
          id: response.messageId,
          content: response.content,
          role: "assistant" as const,
          timestamp: new Date().toISOString(),
        };
        setMessages((prev) => [...prev, aiMessage]);
      } catch (error) {
        // 에러 처리
        console.error("메시지 전송 실패:", error);
        toast.error("메시지 전송에 실패했습니다");
      } finally {
        // 전송 완료
        setIsSending(false);
        sessionStorage.removeItem("isAnswering");
      }
    },
    [currentSessionId, canSend, createTempUserMessage]
  );

  return {
    isSending,
    messages,
    sendMessage,
  };
};
```

## 주석 작성 체크리스트

코드를 작성할 때 다음을 확인하세요:

- [ ] 모든 export된 함수/컴포넌트에 JSDoc 주석 작성
- [ ] Props 타입의 각 필드에 설명 추가
- [ ] 훅의 @param, @returns, @example 작성
- [ ] API 함수의 @throws 작성 (에러 처리)
- [ ] 복잡한 로직에 섹션 구분 주석 추가
- [ ] 선택적 Props에 @default 명시
- [ ] 콜백 함수의 파라미터 설명 추가
- [ ] 사용 예시 코드가 실제로 동작하는지 확인
