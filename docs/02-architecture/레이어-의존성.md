# 레이어 의존성 규칙

📍 **위치**: [홈](../00-README.md) > [아키텍처](../02-architecture/) > 레이어 의존성

## 의존성 계층 구조

```
app → layouts → features → shared
```

**핵심 원칙**: 상위 레이어는 하위 레이어만 import 가능

> **참고**: `widgets` 레이어는 현재 프로젝트에서 사용하지 않습니다. 향후 복합 기능이 필요할 경우 `widgets` 레이어를 추가하여 `app → layouts → widgets → features → shared` 구조로 확장할 수 있습니다.

---

## 올바른 의존성

```tsx
// ✅ app → features
import { SideBar } from "@/features/sidebar/components";
import { LoginForm } from "@/features/auth/components";

// ✅ app → layouts
import ConditionalLayout from "@/layouts/ConditionalLayout";

// ✅ features → shared
import { cn } from "@/shared/utils/cn.util";
import { useInfiniteScroll } from "@/shared/hooks";

// ✅ features → 외부 라이브러리
import { SolidPrimary } from "@itandsy/react-common";
import { useQuery } from "@tanstack/react-query";
```

## 잘못된 의존성

```tsx
// ❌ shared → features (금지!)
// shared는 최하위 레이어로 features를 import할 수 없음
import { ChatContainer } from "@/features/chat/components";

// ❌ features → features (금지!)
// 다른 feature를 직접 import하면 순환 의존성 발생 가능
import { SideBar } from "@/features/sidebar/components";

// ❌ features → layouts (금지!)
// features는 layouts보다 하위 레이어
import { Header } from "@/layouts/Header";

// ❌ shared → layouts (금지!)
// shared는 최하위 레이어
import ConditionalLayout from "@/layouts/ConditionalLayout";
```

## 계층별 역할

### app (최상위)

- 라우팅 및 페이지 정의
- layouts, features 조합하여 페이지 구성

### layouts

- 전역 레이아웃 컴포넌트 (Header, Footer, ConditionalLayout)
- features 사용 가능

### features

- 비즈니스 기능 단위 (auth, chat, post 등)
- shared만 사용 가능
- 다른 features 직접 import 금지

### shared (최하위)

- 공통 유틸, 훅, 타입, 상수
- 다른 레이어 import 금지
- 외부 라이브러리만 사용 가능

## 해결 방법

### 문제: features 간 코드 공유가 필요한 경우

**❌ 잘못된 방법**

```tsx
// features/chat/components/ChatInput.tsx
import { useAuth } from "@/features/auth/hooks"; // 금지!
```

**✅ 올바른 방법 1: shared로 이동**

```tsx
// features/auth/hooks/use-auth.ts → shared/hooks/use-auth.ts로 이동
// features/chat/components/ChatInput.tsx
import { useAuth } from "@/shared/hooks";
```

**✅ 올바른 방법 2: Props로 전달**

```tsx
// app/chat/page.tsx에서 조합
import { useAuth } from "@/features/auth/hooks";
import { ChatInput } from "@/features/chat/components";

export default function ChatPage() {
  const { user } = useAuth();
  return <ChatInput user={user} />;
}
```
