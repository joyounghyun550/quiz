## 1. 데이터 페칭은 Server Component에서

```tsx
// ✅ 좋은 예 - Server Component에서 데이터 페칭
// app/dashboard/page.tsx
export default async function DashboardPage() {
  // 서버에서 병렬로 데이터 페칭
  const [user, posts, stats] = await Promise.all([getUser(), getPosts(), getStats()]);

  return (
    <div>
      <UserProfile user={user} />
      <PostList posts={posts} />
      <Stats data={stats} />
    </div>
  );
}
```

## 2. Streaming & Suspense 활용

느린 컴포넌트를 Suspense로 분리하여 빠른 콘텐츠를 먼저 표시합니다.

```tsx
// app/dashboard/page.tsx
import { Suspense } from "react";
import { UserProfile } from "@/features/user/components";
import { PostList } from "@/features/post/components";

export default function DashboardPage() {
  return (
    <div>
      {/* ✅ 빠른 콘텐츠는 즉시 표시 */}
      <h1>대시보드</h1>

      {/* ✅ 느린 콘텐츠는 Suspense로 분리 */}
      <Suspense fallback={<div>사용자 정보 로딩 중...</div>}>
        <UserProfile />
      </Suspense>

      <Suspense fallback={<div>게시글 로딩 중...</div>}>
        <PostList />
      </Suspense>
    </div>
  );
}
```

## 3. Dynamic Import로 클라이언트 번들 최적화

무거운 컴포넌트는 동적 import로 필요할 때만 로드합니다.

```tsx
// app/posts/[id]/page.tsx
import dynamic from "next/dynamic";

// ✅ 사용하지 않을 수도 있는 무거운 컴포넌트는 동적 import
const HeavyEditor = dynamic(() => import("@/features/post/components/HeavyEditor"), {
  loading: () => <p>에디터 로딩 중...</p>,
  ssr: false, // 클라이언트에서만 로드
});

export default function PostEditPage() {
  return (
    <div>
      <h1>게시글 수정</h1>
      <HeavyEditor />
    </div>
  );
}
```

## 4. 로딩 & 에러 처리

### loading.tsx

```tsx
// app/community/loading.tsx
export default function Loading() {
  return <div>로딩 중...</div>;
}
```

### error.tsx

```tsx
// app/community/error.tsx
"use client";

export default function Error({ error, reset }: { error: Error & { digest?: string }; reset: () => void }) {
  return (
    <div>
      <h2>에러가 발생했습니다</h2>
      <button onClick={() => reset()}>다시 시도</button>
    </div>
  );
}
```

> **참고**: 전역 `error.tsx`, `loading.tsx`, `not-found.tsx`는 `app/` 루트에 위치하며, 특정 라우트의 에러/로딩은 해당 라우트 폴더에 별도로 생성할 수 있습니다.

## 5. 실제 프로젝트 예시

### 예시 1: 인증 콜백 페이지 (Server Component)

```tsx
// app/(auth)/auth/callback/page.tsx - Server Component
import { redirect } from "next/navigation";
import { AuthCallbackHandler } from "@/features/auth/components";

type Props = {
  searchParams: { token?: string };
};

/**
 * OAuth 콜백 페이지
 * 서버에서 토큰을 검증하고 리다이렉트 처리합니다.
 */
export default async function AuthCallbackPage({ searchParams }: Props) {
  const params = await searchParams;
  const token = typeof params.token === "string" ? params.token : undefined;

  // ✅ 서버에서 토큰 검증
  if (!token) {
    redirect("/login?error=no_token");
  }

  // ✅ Client Component에 토큰 전달
  return <AuthCallbackHandler token={token} />;
}
```

### 예시 3: 게시글 목록 페이지 (Hybrid)

```tsx
// app/posts/page.tsx - Server Component
import { PostList } from "@/features/post/components";
import { PostSearchBar } from "@/features/post/components/PostSearchBar"; // Client Component

/**
 * 게시글 목록 페이지
 * 서버에서 초기 데이터를 페칭하고, 클라이언트에서 인터랙션 처리합니다.
 */
export default async function PostsPage() {
  // ✅ 서버에서 초기 데이터 페칭
  const initialPosts = await fetch("https://api.example.com/posts").then((res) => res.json());

  return (
    <div>
      <h1>게시글 목록</h1>

      {/* ✅ 검색 인터랙션 - Client Component */}
      <PostSearchBar />

      {/* ✅ 목록 표시 - Server Component 데이터를 Client Component에 전달 */}
      <PostList initialData={initialPosts} />
    </div>
  );
}
```

## 핵심 원칙 요약

| 원칙                       | 설명                                    |
| -------------------------- | --------------------------------------- |
| **Suspense로 로딩 최적화** | 느린 컴포넌트를 분리하여 UX 개선        |
| **Dynamic Import 활용**    | 무거운 컴포넌트는 필요할 때만 로드      |
| **병렬 데이터 페칭**       | `Promise.all()`로 여러 데이터 동시 로드 |
| **loading.tsx 활용**       | 자동 로딩 UI 처리                       |
| **error.tsx 활용**         | 에러 경계 설정으로 graceful degradation |
