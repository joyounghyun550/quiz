# 환경 변수 관리 규칙

📍 **위치**: [홈](../00-README.md) > [Next.js 특화](../07-nextjs-specific/) > 환경 변수

---

## 파일 구조

```
프로젝트 루트/
├── .env                    # 기본 환경 변수 (git에 포함, 민감하지 않은 값)
├── .env.local              # 로컬 개발용 (git 제외, 민감한 값)
├── .env.development        # 개발 서버용
├── .env.production         # 프로덕션 빌드용
└── .env.example            # 환경 변수 템플릿 (git에 포함)
```

---

## 네이밍 규칙

```bash
# ✅ 브라우저에서 접근 가능 (클라이언트)
NEXT_PUBLIC_API_URL=https://api.example.com
NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX
NEXT_PUBLIC_SITE_NAME=My App

# ✅ 서버에서만 접근 가능 (Server Component, API Route)
DATABASE_URL=postgresql://...
JWT_SECRET=your-secret-key
INTERNAL_API_KEY=secret-api-key
```

---

## 우선순위 (높은 순)

1. `.env.$(NODE_ENV).local` - 환경별 로컬 (git 제외)
2. `.env.local` - 로컬 오버라이드 (git 제외)
3. `.env.$(NODE_ENV)` - 환경별 설정
4. `.env` - 기본 설정

## 타입 안전한 환경 변수 접근

```typescript
// env.ts - 환경 변수 검증 및 타입 정의
const requiredEnvVars = ["NEXT_PUBLIC_API_URL", "DATABASE_URL"] as const;

// 앱 시작 시 필수 환경 변수 검증
export function validateEnv() {
  const missing = requiredEnvVars.filter((key) => !process.env[key]);

  if (missing.length > 0) {
    throw new Error(`Missing required environment variables: ${missing.join(", ")}`);
  }
}

// 타입 안전한 환경 변수 객체
export const env = {
  // 클라이언트용 (NEXT_PUBLIC_ 접두사)
  apiUrl: process.env.NEXT_PUBLIC_API_URL!,
  siteName: process.env.NEXT_PUBLIC_SITE_NAME ?? "My App",

  // 서버용
  databaseUrl: process.env.DATABASE_URL!,
  jwtSecret: process.env.JWT_SECRET!,
} as const;
```

## .env.example 템플릿

```bash
# .env.example - 팀원들이 참고할 템플릿

# === 클라이언트 환경 변수 (브라우저 노출됨) ===
NEXT_PUBLIC_API_URL=https://api.example.com
NEXT_PUBLIC_SITE_NAME=My App

# === 서버 환경 변수 (비공개) ===
DATABASE_URL=postgresql://user:password@localhost:5432/dbname
JWT_SECRET=your-jwt-secret-min-32-chars

# === 선택적 환경 변수 ===
# NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX
# SENTRY_DSN=https://xxx@sentry.io/xxx
```

## 주의사항

| 규칙                       | 설명                                          |
| -------------------------- | --------------------------------------------- |
| `NEXT_PUBLIC_` 접두사      | 브라우저에 노출됨. 민감한 정보 절대 포함 금지 |
| `.env.local` 필수 git 제외 | `.gitignore`에 `.env*.local` 추가 확인        |
| 기본값 설정                | 선택적 변수는 `??` 연산자로 기본값 제공       |
| 빌드 타임 vs 런타임        | 환경 변수는 빌드 시점에 번들됨 (Edge 제외)    |
