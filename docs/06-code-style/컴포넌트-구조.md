## 기본 컴포넌트 구조

### 컴포넌트 파일

````typescript
// LoginForm.tsx
// ============================================
// 1. Import
// ============================================
import { useState, useEffect } from "react";

const OAUTH_REDIRECT_URL = process.env.NEXT_PUBLIC_OAUTH_URL;

// ============================================
// 3. 컴포넌트
// ============================================

 * 로그인 폼 컴포넌트
 *
 * 소셜 로그인 (구글, 카카오, 네이버)을 제공합니다.
 *
 * @param props - LoginFormProps
 * @example
 * ```tsx
 * <LoginForm onSuccess={() => router.push('/dashboard')} />
 * ```
 */
const LoginForm = ({ onSuccess }: LoginFormProps) => {
  // 3-1. Hooks
  const [isLoading, setIsLoading] = useState(false);
  const router = useRouter();

  // 3-2. 함수
  const handleLogin = (provider: "google" | "kakao" | "naver") => {
    setIsLoading(true);
    // 로그인 로직
  };

  // 3-3. useEffect
  useEffect(() => {
    // 초기화 로직
  }, []);

  // 3-4. 렌더링
  return (
    <div>
      <SolidPrimary label="구글로 로그인" onClick={() => handleLogin("google")} disabled={isLoading} />
    </div>
  );
};

// ============================================
// 4. Export
// ============================================

````

### 타입 파일

````typescript
// LoginForm.type.ts
/**
 * LoginForm 컴포넌트의 Props 타입
 */
export type LoginFormProps = {
  /**
   * 로그인 성공 시 호출되는 콜백 함수
   *
   * @example
   * ```tsx
   * <LoginForm onSuccess={() => router.push('/dashboard')} />

  /**
   * 로그인 버튼 비활성화 여부
   *
   * @default false
   */
  disabled?: boolean;
};
````

## 복잡한 컴포넌트 구조

복잡한 로직을 가진 컴포넌트는 섹션을 더 세분화합니다:

```typescript
// app/chat/page.tsx
"use client";

// ============================================
// 1. Import
// ============================================
import { useState, useEffect, useCallback, useRef } from "react";
import { useRouter, usePathname, useSearchParams } from "next/navigation";
import { ChatContainer, ChatInput, ChatMessageList } from "@/features/chat/components";
import { useChatSession, useChatMessage } from "@/features/chat/hooks";
import type { ChatMessage } from "@/features/chat/types";

// ============================================
// 2. 상수
// ============================================
const MAX_MESSAGE_LENGTH = 1000;
const GUEST_QUESTION_LIMIT = 5;
const USER_QUESTION_LIMIT = 50;

// ============================================
// 3. 컴포넌트
// ============================================
/**
 * 채팅 페이지
 *
 * 실시간 메시지 표시 및 전송 기능을 제공합니다.
 *
 * ## 아키텍처
 * - **UI**: 컴포넌트로 분리 (ChatContainer, ChatInput, ChatMessageList)
 * - **상태**: hooks로 분리 (useChatSession, useChatMessage)
 * - **로직**: utils로 분리
 * - **page.tsx**: 조합 레이어 (hooks + components)
 *
 * ## 주요 기능
 * - 회원/비회원 모두 사용 가능
 * - 실시간 메시지 스트리밍
 * - localStorage 기반 세션 관리
 */
const ChatPage = () => {
  // ============================================
  // 3-1. Next.js Hooks
  // ============================================
  const router = useRouter();
  const pathname = usePathname();
  const searchParams = useSearchParams();

  // ============================================
  // 3-2. 상태 관리
  // ============================================
  const [messages, setMessages] = useState<ChatMessage[]>([]);
  const [inputValue, setInputValue] = useState("");
  const [isLoggedIn, setIsLoggedIn] = useState(false);

  // ============================================
  // 3-3. Refs
  // ============================================
  const textBoxRef = useRef<HTMLDivElement>(null);
  const messageListRef = useRef<HTMLDivElement>(null);

  // ============================================
  // 3-4. 커스텀 훅
  // ============================================
  const { currentSessionId, startNewSession, loadGuestSession } = useChatSession(isLoggedIn);

  const { isSending, sendMessage } = useChatMessage({
    isLoggedIn,
    currentSessionId,
    messages,
    setMessages,
  });

  // ============================================
  // 3-5. 초기화
  // ============================================
  /**
   * 컴포넌트 마운트 시 초기화
   * - 로그인 여부 확인
   * - 세션 로드
   * - 메시지 히스토리 로드
   */
  useEffect(() => {
    // 초기화 로직
  }, []);

  // ============================================
  // 3-6. 이벤트 핸들러
  // ============================================
  /**
   * 메시지 전송 핸들러
   * Enter 키 또는 전송 버튼 클릭 시 호출됩니다.
   */
  const handleSendMessage = useCallback(async () => {
    if (!inputValue.trim() || isSending) return;

    await sendMessage(inputValue);
    setInputValue("");

    // 스크롤을 최하단으로 이동
    if (messageListRef.current) {
      messageListRef.current.scrollTop = messageListRef.current.scrollHeight;
    }
  }, [inputValue, isSending, sendMessage]);

  /**
   * 입력값 변경 핸들러
   */
  const handleInputChange = useCallback((value: string) => {
    if (value.length <= MAX_MESSAGE_LENGTH) {
      setInputValue(value);
    }
  }, []);

  // ============================================
  // 3-7. 렌더링
  // ============================================
  return (
    <ChatContainer>
      <ChatMessageList ref={messageListRef} messages={messages} />
      <ChatInput
        value={inputValue}
        onChange={handleInputChange}
        textBoxRef={textBoxRef}
        isLoggedIn={isLoggedIn}
        isSending={isSending}
        handleSendMessage={handleSendMessage}
      />
    </ChatContainer>
  );
};

// ============================================
// 4. Export
// ============================================
export default ChatPage;
```

## Server Component 구조

Server Component는 async 함수로 작성하며, 데이터 페칭을 먼저 수행합니다:

```typescript
// app/posts/[id]/page.tsx
import type { Metadata } from "next";
import { getPostById } from "@/features/post/api";
import { PostDetail } from "@/features/post/components";

type Props = {
  params: { id: string };
};

/**
 * 게시글 상세 페이지 메타데이터 생성
 * SEO 최적화를 위해 동적으로 메타데이터를 생성합니다.
 */
export async function generateMetadata({ params }: Props): Promise<Metadata> {
  const post = await getPostById(params.id);

  return {
    title: post.title,
    description: post.excerpt,
    openGraph: {
      title: post.title,
      description: post.excerpt,
      images: [post.thumbnailUrl],
    },
  };
}

/**
 * 게시글 상세 페이지
 *
 * 서버에서 게시글 데이터를 페칭하여 표시합니다.
 * SEO 최적화를 위해 Server Component로 구현되었습니다.
 */
export default async function PostDetailPage({ params }: Props) {
  // ============================================
  // 1. 서버에서 데이터 페칭
  // ============================================
  const post = await getPostById(params.id);

  // ============================================
  // 2. 렌더링
  // ============================================
  return (
    <div className="container mx-auto py-8">
      <PostDetail post={post} />
    </div>
  );
}
```

## 컴포넌트 구조 체크리스트

- [ ] 파일 상단에 'use client' 또는 'use server' 지시어 (필요시)
- [ ] Import는 카테고리별로 구분하고 주석 추가
- [ ] 상수는 컴포넌트 외부에 선언
- [ ] 컴포넌트에 TSDoc 주석 작성
- [ ] Props 타입은 별도 파일로 분리
- [ ] Hooks는 컴포넌트 내부 최상단에 배치
- [ ] 함수는 useCallback으로 메모이제이션 (필요시)
- [ ] useEffect는 함수 선언 다음에 배치
- [ ] 복잡한 로직은 섹션 구분 주석 사용
- [ ] Default export 사용

## 타입 Import 규칙

- 타입 import는 `import type` 구문을 사용합니다
- 타입은 해당 카테고리 내에서 일반 import 다음에 배치합니다

```typescript
// ✅ 올바른 타입 import
import { useCurrentUserProfileQuery } from "@/features/auth/hooks";
import type { UserProfile } from "@/features/auth/api/auth.api.type";
import type { LoginFormProps } from "@/features/auth/components/LoginForm.type";

// ❌ 잘못된 타입 import (import type 없음)
import { UserProfile } from "@/features/auth/api/auth.api.type";
```
