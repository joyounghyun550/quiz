## 컴포넌트 Props 타입은 별도 파일로 분리

```typescript
// TermsAgreementDialog.type.ts
export type TermsAgreementDialogProps = {
  isOpen: boolean;
  onClose: () => void;
  onAgree: () => void;
};

// TermsAgreementDialog.tsx
import type { TermsAgreementDialogProps } from "@/features/auth/components/TermsAgreementDialog.type";

const TermsAgreementDialog = ({ isOpen, onClose, onAgree }: TermsAgreementDialogProps) => {
  // ...
};
```

## Interface vs Type

```typescript
// ✅ Interface - 객체 구조, 확장 가능
interface User {
  id: string;
  name: string;
}

interface Admin extends User {
  role: "admin";
  permissions: string[];
}

// ✅ Type - 유니온, 교차, Props, 제네릭
type UserStatus = "active" | "inactive";
type ApiResponse<T> = { data: T; status: number };
type ButtonProps = { label: string; onClick: () => void };
```

### 언제 무엇을 사용할까?

| 사용 상황          | 권장        | 예시                             |
| ------------------ | ----------- | -------------------------------- |
| 객체 구조 정의     | `interface` | `interface User { ... }`         |
| 확장이 필요한 경우 | `interface` | `interface Admin extends User`   |
| 유니온 타입        | `type`      | `type Status = "a" \| "b"`       |
| Props 정의         | `type`      | `type ButtonProps = { ... }`     |
| 제네릭 타입        | `type`      | `type Response<T> = { data: T }` |

## 타입 파일 네이밍

| 종류           | 규칙                                 | 예시                           |
| -------------- | ------------------------------------ | ------------------------------ |
| 컴포넌트 Props | `ComponentName.type.ts` (PascalCase) | `TermsAgreementDialog.type.ts` |
| 도메인 타입    | `domain.type.ts` (kebab-case)        | `pagination.type.ts`           |
| API 타입       | `api-name.api.type.ts` (kebab-case)  | `auth.api.type.ts`             |
| Feature 타입   | `feature-name.type.ts`               | `SideBarSetting.type.ts`       |

## 타입 Import 규칙

```typescript
// ✅ import type 사용 (런타임에 제거됨)
import type { UserProfile } from "@/features/auth/api/auth.api.type";
import type { LoginFormProps } from "@/features/auth/components/LoginForm.type";

// ❌ import type 없이 사용 (잘못됨)
import { UserProfile } from "@/features/auth/api/auth.api.type";
```

## Props 타입 작성 패턴

```typescript
// ComponentName.type.ts
/**
 * ComponentName 컴포넌트의 Props 타입
 */
export type ComponentNameProps = {
  /**
   * 필수 필드 설명
   */
  requiredField: string;

  /**
   * 선택적 필드 설명
   * @default false
   */
  optionalField?: boolean;

  /**
   * 콜백 함수 설명
   */
  onAction?: () => void;

  /**
   * children
   */
  children?: React.ReactNode;
};
```
