## 컴포넌트 Props 타입 분리

컴포넌트 Props 타입은 별도의 `.type.ts` 파일로 분리합니다.

```typescript
// TermsAgreementDialog.type.ts
export type TermsAgreementDialogProps = {
  isOpen: boolean;
  onClose: () => void;
  onAgree: () => void;
};

// TermsAgreementDialog.tsx
import type { TermsAgreementDialogProps } from "@/features/auth/components/TermsAgreementDialog.type";

const TermsAgreementDialog = ({ isOpen, onClose, onAgree }: TermsAgreementDialogProps) => {
  // ...
};
```

## 타입 파일 네이밍 규칙

| 타입 종류      | 네이밍 규칙                          | 예시                           |
| -------------- | ------------------------------------ | ------------------------------ |
| 컴포넌트 Props | `ComponentName.type.ts` (PascalCase) | `TermsAgreementDialog.type.ts` |
| 도메인 타입    | `domain.type.ts` (kebab-case)        | `pagination.type.ts`           |
| API 타입       | `api-name.api.type.ts` (kebab-case)  | `auth.api.type.ts`             |
| Feature 타입   | `feature-name.type.ts` (kebab-case)  | `SideBarSetting.type.ts`       |

## 폴더 구조 예시

```
src/
├── features/
│   └── auth/
│       ├── api/
│       │   ├── auth.api.ts
│       │   └── auth.api.type.ts      # API 타입
│       ├── components/
│       │   ├── LoginForm.tsx
│       │   └── LoginForm.type.ts     # 컴포넌트 Props 타입
│       └── types/
│           └── index.ts              # Feature 도메인 타입
│
└── shared/
    └── types/
        ├── pagination.type.ts        # 공통 도메인 타입
        └── index.ts
```

## Props 타입 작성 예시

```typescript
// features/chat/components/ChatInput.type.ts

/**
 * ChatInput 컴포넌트의 Props 타입
 */
export type ChatInputProps = {
  /**
   * 입력 필드의 현재 값
   * 부모 컴포넌트에서 상태로 관리되어야 합니다.
   */
  value: string;

  /**
   * 입력값 변경 핸들러
   * 사용자가 텍스트를 입력할 때마다 호출됩니다.
   *
   * @param value - 변경된 입력값
   */
  onChange: (value: string) => void;

  /**
   * 메시지 전송 중 여부
   * true인 경우 입력 필드와 전송 버튼이 비활성화됩니다.
   */
  isSending: boolean;

  /**
   * 메시지 전송 핸들러
   *
   * @default undefined
   */
  handleSendMessage?: () => void | Promise<void>;
};
```

## API 타입 작성 예시

```typescript
// features/auth/api/auth.api.type.ts

/**
 * 사용자 프로필 응답 타입
 */
export interface UserProfile {
  id: string;
  name: string;
  email: string;
  isTermsAgreed: boolean;
}

/**
 * 약관 동의 저장 요청 타입
 */
export type SaveTermsAgreementRequest = {
  termsAgreed: boolean;
  privacyAgreed: boolean;
  marketingAgreed?: boolean;
};

/**
 * 회원 탈퇴 요청 타입
 */
export type WithdrawRequest = {
  reason: string;
  feedback?: string;
};
```

// features/auth/types/index.ts
