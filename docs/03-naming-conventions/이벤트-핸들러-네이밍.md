# 이벤트 핸들러 네이밍

📍 **위치**: [홈](../00-README.md) > [네이밍 규칙](../03-naming-conventions/) > 이벤트 핸들러 네이밍

---

## 네이밍 규칙

- **정의할 때**: `handle + 동작명`
- **Props로 전달**: `on + 동작명`

---

## 기본 패턴

### 컴포넌트 내부에서 정의

```tsx
const Component = () => {
  // handle + 동작명
  const handleClick = () => {
    console.log("클릭됨");
  };

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    console.log("제출됨");
  };

  const handleChange = (value: string) => {
    console.log("변경됨:", value);
  };

  return <button onClick={handleClick}>클릭</button>;
};
```

## Props로 전달하는 패턴

### 타입 정의

```tsx
// SideBar.type.ts
export type SideBarProps = {
  onChatClick?: (chatId: string) => void;
  onSettingClick?: () => void;
  onClose?: () => void;
};
```

### 컴포넌트 구현

```tsx
// SideBar.tsx
import type { SideBarProps } from "./SideBar.type";

const SideBar = ({ onChatClick, onSettingClick, onClose }: SideBarProps) => {
  return (
    <div>
      <button onClick={() => onChatClick?.("chat-123")}>채팅</button>
      <button onClick={onSettingClick}>설정</button>
      <button onClick={onClose}>닫기</button>
    </div>
  );
};

export default SideBar;
```

### 부모 컴포넌트에서 사용

```tsx
// ChatPage.tsx
const ChatPage = () => {
  // 부모에서는 handle + 동작명
  const handleChatClick = (chatId: string) => {
    console.log("선택된 채팅:", chatId);
  };

  const handleSettingClick = () => {
    console.log("설정 클릭");
  };

  const handleClose = () => {
    console.log("사이드바 닫기");
  };

  return <SideBar onChatClick={handleChatClick} onSettingClick={handleSettingClick} onClose={handleClose} />;
};
```

## 일반적인 이벤트 핸들러 이름

| 이벤트 종류 | Props 이름 | 핸들러 이름    | 설명                  |
| ----------- | ---------- | -------------- | --------------------- |
| 클릭        | `onClick`  | `handleClick`  | 버튼, 링크 클릭       |
| 변경        | `onChange` | `handleChange` | 입력값 변경           |
| 제출        | `onSubmit` | `handleSubmit` | 폼 제출               |
| 포커스      | `onFocus`  | `handleFocus`  | 입력 필드 포커스      |
| 블러        | `onBlur`   | `handleBlur`   | 입력 필드 포커스 해제 |
| 닫기        | `onClose`  | `handleClose`  | 모달, 사이드바 닫기   |
| 열기        | `onOpen`   | `handleOpen`   | 모달, 사이드바 열기   |
| 삭제        | `onDelete` | `handleDelete` | 항목 삭제             |
| 저장        | `onSave`   | `handleSave`   | 데이터 저장           |
| 취소        | `onCancel` | `handleCancel` | 작업 취소             |

## 구체적인 동작 명시

### 일반적인 이름보다 구체적인 이름 사용

```tsx
// ❌ 모호함
const handleClick = () => { ... }
const handleClick2 = () => { ... }

// ✅ 구체적
const handleChatClick = (chatId: string) => { ... }
const handleSettingClick = () => { ... }
const handleLogoutClick = () => { ... }
```

### Props에서도 구체적으로

```tsx
// SideBarProps
export type SideBarProps = {
  // ✅ 구체적인 이름
  onChatClick?: (chatId: string) => void;
  onSettingClick?: () => void;
  onLogoutClick?: () => void;

  // ❌ 모호한 이름 (피하기)
  onClick?: () => void;
  onItemClick?: () => void;
};
```

## 특수 케이스

### 비동기 핸들러

```tsx
const handleSubmit = async (e: React.FormEvent) => {
  e.preventDefault();
  await saveData();
};
```

### 매개변수가 있는 핸들러

```tsx
const handleItemClick = (itemId: string) => {
  console.log("선택된 항목:", itemId);
};

// 사용
<button onClick={() => handleItemClick("123")}>항목 1</button>;
```
