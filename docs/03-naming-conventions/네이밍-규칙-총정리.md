## 기본 표기법

| 대상                  | 표기법           | 예시                                 |
| --------------------- | ---------------- | ------------------------------------ |
| 폴더명                | kebab-case       | `post-card/`, `user-profile/`        |
| 컴포넌트 파일         | PascalCase       | `PostCard.tsx`, `Button.tsx`         |
| 타입/훅/API/유틸 파일 | kebab-case       | `post.type.ts`, `use-posts-query.ts` |
| 컴포넌트명            | PascalCase       | `PostCard`, `UserProfile`            |
| 변수/함수             | camelCase        | `userName`, `fetchUsers`             |
| 상수                  | UPPER_SNAKE_CASE | `API_BASE_URL`, `MAX_COUNT`          |
| 타입/인터페이스       | PascalCase       | `User`, `ApiResponse`                |

## 레이어별 네이밍 가이드

### features - 도메인 접두사 사용

```tsx
LoginForm.tsx;
ChatContainer.tsx;
SideBar.tsx;
```

### widgets - 복합 기능 명시 (현재 미사용)

향후 복합 기능이 필요할 경우 사용

### shared/ui - 순수 UI (도메인 접두사 없음)

공통 UI 컴포넌트 (shadcn/ui 또는 커스텀 컴포넌트)

### app 폴더 - Next.js 파일명 고정

```
page.tsx
layout.tsx
error.tsx
not-found.tsx
loading.tsx
```

### layouts - Layout 접미사

```tsx
ConditionalLayout.tsx;
Header.tsx;
Footer.tsx;
```

---

## 파일 확장자 규칙

### TypeScript 파일

- `.ts` - 일반 TypeScript 파일 (유틸, API 등)
- `.tsx` - React 컴포넌트 파일
- `.type.ts` - 타입 정의 전용 파일

### 예시

```
components/
├── PostCard.tsx           # 컴포넌트
├── PostCard.type.ts       # 컴포넌트 Props 타입
api/
├── post.api.ts            # API 함수
├── post.api.type.ts       # API 타입
utils/
├── date.util.ts           # 유틸리티 함수
```

---

## 규칙 요약

1. **폴더와 파일(컴포넌트 제외)**: kebab-case
2. **컴포넌트**: PascalCase
3. **변수와 함수**: camelCase
4. **상수**: UPPER_SNAKE_CASE
5. **타입**: PascalCase
