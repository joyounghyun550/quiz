## 💡 용어 정리

| 용어             | 의미                                                       |
| ---------------- | ---------------------------------------------------------- |
| FSD              | Feature-Sliced Design - 기능 단위로 폴더를 나누는 아키텍처 |
| Server Component | 서버에서 렌더링되는 React 컴포넌트 (Next.js 기본값)        |
| Client Component | 브라우저에서 실행되는 컴포넌트 (`'use client'` 선언 필요)  |
| TanStack Query   | 서버 상태 관리 라이브러리 (데이터 페칭, 캐싱)              |
| Zustand          | 클라이언트 전역 상태 관리 라이브러리                       |
| TSDoc            | TypeScript용 JSDoc 주석 규격                               |
| kebab-case       | `like-this-name` 형식 (폴더, 훅, 유틸 파일)                |
| PascalCase       | `LikeThisName` 형식 (컴포넌트 파일, 타입)                  |
| camelCase        | `likeThisName` 형식 (변수, 함수)                           |
