## @tanstack/react-query

서버 상태 관리 및 데이터 페칭을 위한 라이브러리입니다.

```tsx
import { useQuery } from "@tanstack/react-query";
import { axiosInstance } from "@/libs/axios";

const usePostsQuery = () => {
  return useQuery({
    queryKey: ["posts"],
    queryFn: async () => {
      const response = await axiosInstance.get("/posts");
      return response.data;
    },
  });
};
```

## sonner

토스트 알림 라이브러리입니다.

```tsx
import { toast } from "sonner";

// 성공 토스트
toast.success("성공했습니다!");

// 에러 토스트
toast.error("에러가 발생했습니다.");

// 로딩 토스트
toast.loading("처리 중...");

// 프로미스 토스트
toast.promise(fetchData(), {
  loading: "로딩 중...",
  success: "완료!",
  error: "실패!",
});
```

## axios

HTTP 클라이언트 라이브러리입니다.

**설정 위치:** `src/libs/axios.ts`

```tsx
// libs/axios.ts
import axios from "axios";

export const axiosInstance = axios.create({
  baseURL: process.env.NEXT_PUBLIC_API_URL,
  timeout: 10000,
  headers: {
    "Content-Type": "application/json",
  },
});

// 요청 인터셉터
axiosInstance.interceptors.request.use((config) => {
  const token = localStorage.getItem("token");
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});
```

## UI 라이브러리 선택 가이드 (대안)

`@itandsy/react-common` 외에 추가적인 UI 컴포넌트가 필요한 경우:

| 라이브러리      | 특징                                          | 추천 상황                           |
| --------------- | --------------------------------------------- | ----------------------------------- |
| **shadcn/ui**   | Radix 기반, 복사/붙여넣기 방식, Tailwind 통합 | 커스터마이징 중요, 번들 크기 최소화 |
| **Radix UI**    | 헤드리스 UI, 접근성 우수                      | 완전한 스타일 커스텀 필요           |
| **Chakra UI**   | 완성된 디자인 시스템                          | 빠른 프로토타이핑                   |
| **Material UI** | 구글 머티리얼 디자인                          | 엔터프라이즈 앱                     |

## shadcn/ui 예시

```tsx
// shadcn/ui 설치 후
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Dialog, DialogContent, DialogHeader, DialogTitle, DialogTrigger } from "@/components/ui/dialog";

const MyComponent = () => {
  return (
    <div>
      <Button variant="default" size="lg">
        클릭하세요
      </Button>
      <Input placeholder="이메일을 입력하세요" />

      <Dialog>
        <DialogTrigger asChild>
          <Button variant="outline">열기</Button>
        </DialogTrigger>
        <DialogContent>
          <DialogHeader>
            <DialogTitle>제목</DialogTitle>
          </DialogHeader>
          <p>다이얼로그 내용</p>
        </DialogContent>
      </Dialog>
    </div>
  );
};
```
