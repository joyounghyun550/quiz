## 1. 'use client' 지시어

- TanStack Query 훅을 사용하는 컴포넌트는 반드시 `'use client'` 필요
- `useState`, `useEffect` 등 React 훅 사용 시에도 필요

```tsx
// ✅ 올바른 사용
"use client";

import { useState } from "react";
import { usePostsQuery } from "@/features/post/hooks";

const PostList = () => {
  const [filter, setFilter] = useState("all");
  const { data } = usePostsQuery();
  // ...
};
```

## 2. async/await in Server Components

- `app/` 폴더의 page.tsx는 기본적으로 서버 컴포넌트
- 서버 컴포넌트에서는 직접 async/await 사용 가능

```tsx
// ✅ 서버 컴포넌트에서 직접 fetch
export default async function Page() {
  const data = await fetch("...");
  return <div>{data}</div>;
}
```

## 3. layouts 폴더 용도

| 항목                 | 설명                                                    |
| -------------------- | ------------------------------------------------------- |
| `layouts/` 폴더      | 재사용 가능한 레이아웃 컴포넌트 저장소                  |
| `ConditionalLayout`  | 경로에 따라 Header/Footer를 조건부로 렌더링             |
| 실제 라우팅 레이아웃 | `app/layout.tsx`에서 `ConditionalLayout`을 사용         |
| 인증 페이지          | `/login`, `/auth`에서는 Header/Footer가 자동으로 숨겨짐 |

## 4. Server Actions (features/.../actions)

- Next.js 14 Server Actions를 사용하는 경우 `actions/` 폴더에 배치
- 예: `features/sidebar/actions/sidebar.action.ts`
- Server Actions는 서버에서만 실행되는 함수로, 'use server' 지시어 필요

```tsx
// features/sidebar/actions/sidebar.action.ts
"use server";

export async function updateSidebarSettings(data: SidebarSettings) {
  // 서버 측 로직
}
```

## 6. 자주하는 실수

### @itandsy/react-common 사용 시

| ❌ 잘못된 사용                               | ✅ 올바른 사용                  | 설명                      |
| -------------------------------------------- | ------------------------------- | ------------------------- |
| `<SolidPrimary>저장</SolidPrimary>`          | `<SolidPrimary label="저장" />` | children 대신 label prop  |
| `onChange={(e) => setValue(e.target.value)}` | `onChange={setValue}`           | TextBox는 value 직접 전달 |

### Server/Client Component 혼용 시

```tsx
// ❌ 페이지 전체를 Client Component로 만들지 말 것
"use client";
export default function Page() { ... }

// ✅ 필요한 부분만 Client Component로 분리
export default function Page() {
  return (
    <div>
      <h1>서버 렌더링</h1>
      <ClientInteraction /> {/* 'use client' */}
    </div>
  );
}
```

## 7. 레이어 의존성 위반

```typescript
// ❌ features 간 직접 import (금지)
import { UserProfile } from "@/features/user/components"; // auth에서 user 직접 import

// ✅ shared를 통해 공유하거나 props로 전달
import { UserProfile } from "@/shared/components";
```
